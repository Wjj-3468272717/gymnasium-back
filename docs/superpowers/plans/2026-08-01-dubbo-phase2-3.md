# Dubbo 分布式改造 Phase 2+3：服务拆分与 RPC 实现

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 从 gym-service-web 单体中拆出 4 个独立的 Dubbo 服务提供者（user / member / course / goods），实现 gym-api RPC 接口，将 gym-service-web 改造为纯消费者（只保留 Controller 层），验证全链路 RPC 调用。

**Architecture:** 每个新服务包含独立的 Spring Boot 启动类、数据源配置、MyBatis-Plus 持久层和 Dubbo Provider 配置。gym-service-web 保留所有 Controller 和 Spring Security 网关职责，通过 `@DubboReference` 远程调用业务服务。短期内所有服务仍共用同一个 MySQL 数据库（gymnasium），数据库拆分留到 Phase 4。

**Tech Stack:** Spring Boot 2.4.4, Dubbo 2.7.8, Nacos 1.4.1, MyBatis-Plus 3.4.1, MySQL 8.0, Java 8

## Global Constraints

- Java 8，所有跨服务传输对象必须实现 Serializable
- Dubbo 2.7.8，Nacos 注册中心地址 `nacos://127.0.0.1:8848`
- 每个 Dubbo Provider 使用不同端口（20881/20882/20883/20884）
- **Phase 2+3 期间所有服务共用同一数据库 gymnasium**，数据库拆分留到 Phase 4
- @DubboService 暴露的接口是 gym-api 中的 RPC 接口（非 MyBatis-Plus IService）
- gym-service-web 中的 Controller 只依赖 gym-api 的 RPC 接口 + @DubboReference
- 不修改任何现有业务逻辑，本次仅为结构拆分
- 所有新增服务模块与 gym-service-web 同级，父 POM 统一管理

## 跨服务依赖矩阵（服务拆分依据）

```
gym-service-user
  ├── sys_user, sys_role, sys_menu, sys_role_menu, sys_user_role, login
  ├── 配置: SpringSecurity, JwtUtils
  └── 被依赖: goods_order(→SysUserService), home(→SysUserService)

gym-service-member
  ├── member, member_card, member_apply, member_recharge, member_role
  └── 被依赖: course(→MemberService), login(→MemberService), home(→MemberService)

gym-service-course
  ├── course, member_course
  └── 依赖: member(→MemberMapper via Dubbo), 被依赖: member_course自身

gym-service-goods
  ├── goods, goods_order, equipment
  └── 依赖: user(→SysUserService via Dubbo)

gym-service-home
  ├── home, suggest, lost, image
  └── 依赖: user(→SysUserService), member(→MemberService), goods(→GoodsOrderService, MaterialService)
```

- [ ] **Step 1: 创建 SysUserRpcProvider**

```java
package com.v1.service.user.provider;

import com.v1.api.dto.PageDTO;
import com.v1.api.dto.PageResultDTO;
import com.v1.api.dto.sys_user.SysUserDTO;
import com.v1.api.sys_user.SysUserRpcService;
import com.v1.service.user.sys_user.entity.SysUser;
import com.v1.service.user.sys_user.service.SysUserService;
import org.apache.dubbo.config.annotation.DubboService;
import org.springframework.beans.BeanUtils;
import org.springframework.beans.factory.annotation.Autowired;

import java.util.stream.Collectors;

@DubboService
public class SysUserRpcProvider implements SysUserRpcService {

    @Autowired
    private SysUserService sysUserService;

    @Override
    public PageResultDTO<SysUserDTO> listUsers(PageDTO page, String nickName, String phone) {
        com.v1.service.user.sys_user.entity.PageParam param =
                new com.v1.service.user.sys_user.entity.PageParam();
        param.setCurrentPage(page.getCurrentPage());
        param.setPageSize(page.getPageSize());
        param.setNickName(nickName);
        param.setPhone(phone);

        com.baomidou.mybatisplus.core.metadata.IPage<SysUser> result =
                sysUserService.list(param);

        PageResultDTO<SysUserDTO> dto = new PageResultDTO<>();
        dto.setCurrentPage(result.getCurrent());
        dto.setPageSize(result.getSize());
        dto.setTotal(result.getTotal());
        dto.setRecords(result.getRecords().stream().map(entity -> {
            SysUserDTO userDTO = new SysUserDTO();
            BeanUtils.copyProperties(entity, userDTO);
            return userDTO;
        }).collect(Collectors.toList()));
        return dto;
    }

    @Override
    public SysUserDTO loadUser(String username) {
        SysUser entity = sysUserService.loadUser(username);
        if (entity == null) return null;
        SysUserDTO dto = new SysUserDTO();
        BeanUtils.copyProperties(entity, dto);
        return dto;
    }

    @Override
    public SysUserDTO getUserById(Long userId) {
        SysUser entity = sysUserService.getById(userId);
        if (entity == null) return null;
        SysUserDTO dto = new SysUserDTO();
        BeanUtils.copyProperties(entity, dto);
        return dto;
    }

    @Override
    public void resetPassword(Long userId, String newPassword) {
        SysUser entity = sysUserService.getById(userId);
        if (entity != null) {
            entity.setPassword(newPassword);
            sysUserService.updateById(entity);
        }
    }
}
```
